Detailed Description

The ID3v1 tag of an ID3, read and written directly (id3v1Read* / id3v1Write*).

Unlike the fields on ID3, these always use the ID3v1 tag, whatever the preferred standard is. Get one from ID3.id3v1; it stays tied to that ID3.

Text fields read as '' when unset and hold at most 30 bytes; id3dev cuts longer values short. Writes that id3dev rejects raise ValueError.

v1 = tag.id3v1
v1.title = "Happier Than Ever"
v1.year = 2021
v1.genre = Genre.POP
