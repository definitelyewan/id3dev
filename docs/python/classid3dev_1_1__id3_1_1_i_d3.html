Detailed Description

Every ID3 tag in one file: an ID3v2 tag, an ID3v1 tag, or both.

Load one with from_file(), or start from scratch with new(); change it, then write it into a file with save(). The C memory is freed when the object is garbage collected, or straight away with close() or a with block.

The genre has its own property, which takes a Genre.

Tag fields
To work on one tag regardless of the preferred standard, use the id3v1 and id3v2 properties instead, e.g. tag.id3v1.title.

These properties read and write through id3dev's "preferred standard": the ID3v2 tag is used when present, otherwise the ID3v1 tag (see id3dev.set_preferred_standard). Reading returns a str, or None when the field isn't set. Assigning a str writes it, and raises ValueError if id3dev rejects it, e.g. when the file has no tags at all.

Property C functions
title id3ReadTitle / id3WriteTitle
artist id3ReadArtist / id3WriteArtist
album_artist id3ReadAlbumArtist / id3WriteAlbumArtist
album id3ReadAlbum / id3WriteAlbum
year id3ReadYear / id3WriteYear (must be a number for ID3v1)
track id3ReadTrack / id3WriteTrack (ID3v2 may hold "3/12")
composer id3ReadComposer / id3WriteComposer
disc id3ReadDisc / id3WriteDisc
lyrics id3ReadLyrics / id3WriteLyrics
comment id3ReadComment / id3WriteComment
with ID3.from_file("song.mp3") as tag:
print(tag.title, tag.artist)
tag.album = "New Album"
tag.save("song.mp3")

◆ genre()

"str | None" id3dev._id3.ID3.genre ( self)

The genre's name, e.g.

"Pop", or None when it isn't set (id3ReadGenre).

Assign a Genre (or its number), or a name as a str. Which tag is written follows the preferred standard, like the other fields: an ID3v1 tag stores the genre's number, an ID3v2 tag stores its name.

tag.genre = Genre.POP
tag.genre = "Pop" # same thing
tag.genre = "Vaporwave" # any text works for an ID3v2 tag
Exceptions
ValueErrorwhen writing to an ID3v1 tag and the value isn't an ID3v1 genre, or id3dev rejects the write (e.g. no tags at all)

◆ id3v2_from_id3v1()

None id3dev._id3.ID3.id3v2_from_id3v1 ( self)

Builds a new ID3v2 tag from the ID3v1 tag (id3ConvertId3v1ToId3v2).

Copies title, artist, album, year, track, genre and comment. The ID3v1 tag is kept. The new tag's version is the preferred standard if that is an ID3v2 version (see id3dev.set_preferred_standard), otherwise 2.3.

Warning
Any existing ID3v2 tag is replaced and its frames are lost. Frame views from frames must not be used afterwards.
Exceptions
ValueErrorif there is no ID3v1 tag or the conversion fails

Set fields and frames, then write the tags into a file with save(). The ID3v2 tag starts with no frames and the ID3v1 tag with blank fields.
