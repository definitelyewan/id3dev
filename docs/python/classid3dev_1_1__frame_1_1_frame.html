Detailed Description

One ID3v2 frame: an ID plus a list of content entries.

The entries follow the frame's layout (its Context). For example, a text frame like TIT2 has an encoding byte followed by the text, and APIC has an encoding, MIME type, picture type, description and image data. Entries are read and written as raw bytes.

Backed by an Id3v2Frame *. A Frame is one of two kinds:

  • owned: made by Frame.new() or ID3.frame(). Python frees it, unless it is passed to ID3.add_frame(), which turns it into a view.
  • view: from ID3.frames. The frame belongs to its tag, so changes change the tag. The view keeps the ID3 alive but never frees the frame. Don't use it after the frame is removed or the ID3 is closed.
title = tag.frame("TIT2") # an owned copy
encoding, text = title.entries
for frame in tag.frames: # views into the tag
print(frame.id, frame.entries)
r = tag.frame("TXXX").reader() # decode entries one at a time
encoding, description, text = r.u8(), r.text(), r.text()

Creates an empty frame, laid out for its ID (id3v2CreateEmptyFrame).

Each entry starts as a single zero byte; fill them with set_entries(), then add the frame to a tag with ID3.add_frame(). The layout comes from id3dev's built-in frames, or the T (text) and W (URL) defaults, then pairs, and otherwise one binary entry.

Parameters
id_frame ID, e.g. "TIT2", or "TT2" for ID3v2.2
versionID3v2 major version: 2, 3 or 4. Match the tag it will be added to.
pairsId3Pairs with layouts for custom frame IDs
Returns
a new owned Frame
Exceptions
ValueErrorif id_ is not 3-4 ASCII characters or id3dev returns nothing

◆ set_entries()

None id3dev._frame.Frame.set_entries ( self,
*bytes values )

Overwrites entries in order, starting from the first.

Entries after the last value are left as they are, so to change the third entry the first two must be passed too. Values longer than their field's max size are cut short; shorter than its min size are padded with zero bytes.

Parameters
valuesone value per entry: bytes-like, or an int 0-255 (such as an Encoding) written as a single byte. Values can't be empty; write b"\x00" for an empty field.
Exceptions
ValueErrorif a value is empty, or there are more values than entries
