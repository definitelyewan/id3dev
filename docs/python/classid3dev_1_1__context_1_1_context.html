Detailed Description

The layout of one kind of frame: an ordered list of fields.

Each field has a type (a ContextType such as LATIN1 or BINARY), a key naming it, and a max and min size. id3dev reads and creates a frame's entries by walking these fields in order. Register a Context under a frame ID with Id3Pairs so id3dev can parse and build that frame.

Backed by an owned C List * of Id3v2ContentContext, freed with listFree when the Context is garbage collected.

Special keys
A field keyed "encoding" sets the text encoding for later ENCODED_STRING fields, and a field keyed "adjustment" sets the max size of a later ADJUSTMENT field.
from id3dev import Context, ContextType, Id3Pairs
ctx = (Context()
.add(ContextType.LATIN1, "label", 64, 1)
.add(ContextType.BINARY, "data", 64, 1))
pairs = Id3Pairs()
pairs["XFRM"] = ctx
