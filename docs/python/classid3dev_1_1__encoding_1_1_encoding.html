Detailed Description

The text encoding byte that starts most ID3v2 text frames.

Values come from the compiled ID3V2_ENCODING_* constants in id3v2Types.h. Because these are ints, one can be passed straight to Frame.set_entries as a one-byte entry.

from id3dev import Encoding, Frame
txxx = Frame.new("TXXX", 3)
txxx.set_entries(Encoding.UTF8, b"producer", "Finneas O'Connell".encode())
