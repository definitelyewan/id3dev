Detailed Description

Custom frame wiring: tells id3dev how to read and create frames it doesn't know.

Maps frame IDs to Context layouts. Pass it to ID3.from_file(pairs=...) to parse custom frames into separate entries, and to Frame.new(pairs=...) to create them. Without it, id3dev reads an unknown frame as one binary blob.

Backed by a HashTableLib HashTable * (the C userPairs argument), freed when the Id3Pairs is garbage collected.

Choosing IDs
When creating a frame, id3dev checks its built-in frames first, then treats any ID starting with "T" as a text frame and "W" as a URL frame, and only then looks here. Custom IDs starting with "X", "Y" or "Z" (e.g. "XFRM") are reserved for experimental frames by the ID3v2 spec and avoid all of that.
pairs = Id3Pairs()
pairs["XFRM"] = (Context()
.add(ContextType.LATIN1, "label", 64, 1)
.add(ContextType.BINARY, "data", 64, 1))
frame = Frame.new("XFRM", 3, pairs)
frame.set_entries(b"hello", b"\x01\x02\x03")
tag = ID3.from_file("song.mp3", pairs=pairs)
