Detailed Description

The type of a Context field: how id3dev reads and writes it.

Values come from the compiled Id3v2ContextType enum in id3v2Types.h. For every type except BIT and ITER, a field's max and min are sizes in bytes. These are ints, so they can be passed anywhere id3dev expects one.

from id3dev import Context, ContextType
ctx = Context().add(ContextType.LATIN1, "label", 64, 1)
