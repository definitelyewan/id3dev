Detailed Description

Reads a frame's entries one at a time, in order (id3v2ReadFrameEntryAs*).

Each read decodes the current entry and moves on to the next, like the C id3v2ReadFrameEntryAs* functions on a ListIter. Reading past the last entry raises IndexError. Get one from Frame.reader().

r = frame.reader() # a TXXX frame
r.u8() # 3 (Encoding.UTF8)
r.text() # "producer"
r.text() # "Finneas O'Connell"
r.remaining # False

Reads the entry as text (id3v2ReadFrameEntryAsChar).

id3dev detects UTF-16 (by its byte order mark), UTF-8 and Latin-1 and converts to UTF-8. Reading stops at the first NUL, so an entry holding several strings returns only the first.
