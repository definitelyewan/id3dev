Detailed Description

An ID3v1 genre: the 80 standard genres plus the Winamp extensions.

Values come from the compiled Genre enum in id3v1Types.h, so they are the numbers ID3v1 stores. Assign one to ID3.genre: an ID3v1 tag stores the number, an ID3v2 tag stores the genre's name (Genre.text).

from id3dev import Genre
tag.genre = Genre.POP
Genre.HIP_HOP.text # "Hip-Hop"
Genre.from_text("hip-hop") # Genre.HIP_HOP
