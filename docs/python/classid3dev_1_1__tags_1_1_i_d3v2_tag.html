Detailed Description

The ID3v2 tag of an ID3, read and written directly (id3v2Read* / id3v2Write*).

Unlike the fields on ID3, these always use the ID3v2 tag, whatever the preferred standard is. Get one from ID3.id3v2; it stays tied to that ID3. Frames, pictures and JSON stay on ID3, which already works on the ID3v2 tag.

Fields
Every field reads as a str, or None when its frame is missing, and is written as a str; writes that id3dev rejects raise ValueError. genre also accepts a Genre, stored as its name.
